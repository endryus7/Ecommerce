# 🛒 ByteLab

> Loja virtual de produtos de tecnologia e gaming desenvolvida como projeto pessoal.
> O visitante pode navegar pelo catálogo de produtos, adicionar itens ao carrinho lateral, acompanhar o total da compra em tempo real e conferir depoimentos de outros clientes, tudo em uma interface responsiva.

![preview do projeto](https://github.com/user-attachments/assets/a6ea6b6f-a3c7-468c-bf3c-0b5ccb3f2f9b)

🌐 **[ByteLab](https://ecommerce-bytelab.vercel.app)**

---

## Tecnologias

React · JavaScript · React Router DOM · Vite · CSS Modules · Lucide React

---

## Funcionalidades

- Vitrine de produtos com listagem dinâmica com consumo de dados mockados em JSON
- Carrinho lateral (sidebar) com adição e remoção de produtos
- Controle de quantidade por produto e cálculo automático do total do carrinho
- Navegação entre Home e página de Produtos via React Router
- Menu responsivo com botão hambúrguer para mobile
- Seção de destaque de produto exclusivo
- Seção de depoimentos de clientes
- Design responsivo com foco em mobile
- Identidade visual própria, com CSS Modules por componente
